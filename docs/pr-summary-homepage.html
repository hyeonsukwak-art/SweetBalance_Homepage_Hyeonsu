Sweet Balance

자사몰 홈페이지 — 무엇을 만들었나요

식단관리를 하는 손님을 위한 첫 번째 홈페이지입니다. 이 문서는 이번 PR에서 만든 화면 구성과 인터뷰 답변이 어떻게 반영되었는지를 정리한 요약 자료예요.

화면 구성

1
첫 화면 (히어로)펀더멘탈 그린 배경 위에 "맛있으면서 식단관리가 되는 메뉴, 여기 있어요" 헤드라인. 식단관리하는 손님을 향한 카피와 두 개의 CTA(식단 추천 / 대표 메뉴 보기)로 시작합니다.
2
대표 제품 소개닭가슴살 샐러드를 BEST 배지와 함께 소개하고, 단백질(28g)·칼로리(320kcal) 정보를 강조합니다.
3
일주일 식단 추천 (주인공 기능)버튼 클릭 한 번으로 월~일 7일 식단표를 생성하는 인터랙티브 기능. 아래에서 자세히 설명합니다.
4
하단 브랜드 소개스윗밸런스의 브랜드 가치(균형·자연스러움·따뜻함·신뢰)와 메뉴 목록을 정리한 푸터입니다.

주인공 기능 일주일 식단 추천

이 페이지에서 가장 공들인 기능

버튼 하나로 완성되는 일주일 식단표

"일주일 식단 추천" 버튼을 누르면, 스윗밸런스 메뉴 풀(닭가슴살 샐러드, 단백질 보울, 연어 포케 등)에서 7가지를 골라 월요일부터 일요일까지 배치합니다. 매일 다른 메뉴가 배정되고, 각 메뉴에는 칼로리·단백질 정보와 특징 배지가 함께 표시됩니다. 생성 후에는 일 평균 칼로리·단백질·메뉴 종류 수를 요약해서 보여주고, "다시 추천받기"로 다른 조합을 계속 받아볼 수 있습니다.

① 버튼 클릭
② 7일 메뉴 랜덤 배정
③ 요일별 카드 애니메이션 표시
④ 평균 칼로리 · 단백질 요약

반영된 인터뷰 답변

질문답변어디에 어떻게 반영했는지
1. 손님은 누구인가요? 식단관리하는 사람 히어로 카피 전체가 "식단관리를 하고 있는 당신"을 향한 문장으로 작성됨
2. 첫 화면에서 느꼈으면 하는 문장 맛있으면서 식단관리가 되는 메뉴다 히어로 헤드라인 문구로 그대로 사용
3. 가장 보여주고 싶은 제품 닭가슴살 샐러드 (단백질 + 맛) 대표 제품 섹션의 유일한 스포트라이트 상품, 단백질/칼로리 수치와 카피에 이유 반영
4. 건강 아이디어 기능 일주일 식단 추천 페이지의 주인공 기능으로 제작, 가장 큰 섹션·가장 정교한 인터랙션으로 구현
5. 페이지 분위기 신선한 초록 + 미니멀 화이트 Sweet Balance 디자인 시스템의 펀더멘탈 그린 + 크림/화이트 배경과 자연스럽게 일치시켜 적용
